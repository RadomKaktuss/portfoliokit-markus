# PortfolioKit — Markus (Beginner-ready)

This repo contains a minimal personal portfolio (index.html + style.css) you can edit and publish on GitHub Pages in under an hour.

What I edited for you
- Added short inline comments in index.html so you know exactly where to change name, bio, skills, project, and contact email.
- Kept CSS minimal and added a few notes at the top explaining how to change colors and fonts.

Quick publish (5–10 minutes)
1. Create a new repository on GitHub (choose "Add README" or not — files can be uploaded).
2. Add `index.html` and `style.css` to the repository root (upload in the web UI or push from your computer).
   - If you prefer a template flow: click "Use this template" on the template repo page (if you create one).
3. On GitHub: go to Settings → Pages.
   - Source: select the branch (usually `main`) and root (/).
   - Save. After a minute your site will be live at:
     `https://<your-username>.github.io/<repo-name>/`
   - Tip: if you name your repo `<your-username>.github.io` the site will be at `https://<your-username>.github.io/`.
4. Visit the URL and confirm the site is live. Edit and push changes anytime; GitHub Pages updates automatically.

One‑hour beginner plan
- 0–10 min: Create the repo and upload the two files.
- 10–20 min: Edit `index.html` — replace name, bio, email, skills, project text.
- 20–30 min: Publish via GitHub Pages and check the site.
- 30–60 min: Share the link on Twitter/LinkedIn and add the site URL to your profiles.
