Generator README

This folder contains a browser-based generator that creates a personalized PortfolioKit ZIP file.

How to use
1. Open generator/index.html in your browser.
2. Fill in your name, bio, skills, project, email, and pick an accent color.
3. Click "Generate ZIP" — a ZIP file with index.html and style.css will download.

No server required — everything runs in your browser using JSZip.
